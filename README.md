# 기억마을 (애니메이션)

매끈한 애니메이션 그림체 버전이에요. 도트 그림이 눈에 아른거리는 분들을 위해 네모 칸 없이 부드러운 선과 색으로 그렸어요.

어르신을 위한 따뜻한 마을 두뇌 미니게임입니다.
마을을 돌아다니며 주민들의 부탁을 들어주고, 작은 게임으로 기억력·주의력·판단력을 자연스럽게 사용합니다.

- 마우스 클릭(또는 손가락 터치)만으로 모두 플레이할 수 있어요. 키보드는 필요 없어요.
- 시간 제한이 없고, 틀려도 "다시 한번 생각해볼까요?"처럼 부드럽게 안내해요.

## 게임

| 장소 | 게임 |
|---|---|
| 우리집 | 오늘 할 일을 기억해요 · 짝꿍 찾기 |
| 우체국 | 숫자를 기억해요 |
| 시장 | 오늘의 장보기 |
| 버스정류장 | 몇 번 버스였지? |
| 공원 | 무엇이 달라졌을까요? |

- **오늘 하루:** 세 가지 게임이 하나의 이야기로 이어지고, 마지막에 낮에 들은 약속 시간을 떠올려요.
- **게임 골라하기:** 게시판에서 원하는 게임을 바로 고를 수 있어요. 준비 중인 게임도 함께 표시돼요.
- **소리:** 화면 위 "소리" 버튼에서 배경음과 효과음을 크게 / 보통 / 작게 / 끄기로 고를 수 있어요.

## 실행하기

`index.html` 파일 하나에 모든 것이 들어 있어요.

- **내 컴퓨터에서:** `index.html`을 더블클릭하면 브라우저에서 바로 실행돼요.
- **휴대폰에서:** 가로로 돌려서 하는 것을 권장해요.
- **글꼴:** 인터넷에 연결되어 있으면 Jua·나눔고딕 글꼴이 적용돼요.

## GitHub Pages로 웹사이트 만들기

1. GitHub에 로그인하고 오른쪽 위 **+** → **New repository**를 눌러요.
2. 이름(예: `memory-village-toon`)을 적고 **Public**을 고른 뒤 **Create repository**를 눌러요.
3. 새 저장소 화면에서 **uploading an existing file**을 누르고, `index.html`과 `README.md`를 끌어다 놓은 뒤 **Commit changes**를 눌러요.
4. 저장소의 **Settings** → 왼쪽 **Pages**로 가요.
5. **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요.
6. 1~2분 뒤 `https://내아이디.github.io/memory-village-toon/` 주소로 접속하면 게임이 열려요.
